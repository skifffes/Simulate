# 实验 3.4：A90 终态多样性审计

## 科学问题

当前环境能否产生多个真实、独立的 A90 成功终态，从而支持跨 A 终态的组合泛化研究？

## 数据来源

`results/experiment_3/data/a_terminal_states.csv`，5 个 A90 成功快照：

- 独立场景 seed：40000000/2/4/6/8；
- 每个都经过 `SkillExpert.skill_a90` 真实执行；
- 成功标志均为 `success=True`；
- 记录 q、物体位姿和 Bullet 快照。

## 结果

| 指标 | 值 |
|---|---:|
| A90 成功快照 | 5 |
| 唯一 q（7 维） | **1** |
| 唯一物体位置 | **1** |
| 唯一物体姿态 | **1** |
| 终态 q | `0.6417456, 0.2961442, -0.3335537, -2.1009291, 0.1384475, 2.3768123, 1.0069058` |
| 终态物体 | `(0.549967, 0.182251, 0.019988)` |
| 终态物体 yaw | ≈ −89.67° |

## 解释

A90 专家使用固定的 PLACE 目标；不同初始物体场景成功后都收敛到同一放置点，机器人回到同一终态 q。5 个快照不是 5 个独立 A 终态，而是同一确定性终态的重复记录。

## 判定

**`A_TERMINAL_DIVERSITY_LIMITED`**

当前平台无法可靠测量跨 A90 终态的组合泛化；任何“多 A 终态”统计都会把重复快照当作独立样本，属于伪重复。

## 未做的事

- 没有通过改变 A90 任务目标、teleport 物体或复制快照并改 seed 来制造虚假多样性；
- 没有跨 A 终态 rollout，因为独立 A 终态数只有 1。

## 边界

这并不表示所有机器人/任务都不可能有多终态；仅表示当前 A90 专家 + 固定 PLACE + 当前场景设置下只能产生一个唯一终态。
