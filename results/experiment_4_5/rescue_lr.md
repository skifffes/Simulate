# 救援学习率实验（明确标记，非严格对照）

**动机**：主实验（AE，峰值 LR 2.5e-5，12,000 步）在 6000/8000 步出现退化
（val MAE 0.0219、B90 推动 cos 0.032 与 −0.058），而 LoRA 同预算单调改善。
为区分"AE 容量不足"与"AE 在当前 LR 下优化不稳"，另做 **0.3× 峰值 LR** 的 AE 训练。

**标记**：本实验**改变了学习率**，不能与主实验合并成"只改微调方式"的严格对照；
只用于诊断 AE 的优化稳定性。数据、batch、seed、Anchor-16、评价器与主实验相同。

## 设置

| 项 | 值 |
| --- | --- |
| 初始权重 | pi05_droid（与主实验相同） |
| 峰值 LR | 2.5e-5 × **0.3 = 7.5e-6**（warmup 1000、cosine 不变） |
| 步数 | 4,000 → 用真实 opt-state 续训到 **12,000**（3.70 epoch） |
| 保存 | 1000/2000/3000/4000 + 6000/8000/10000/12000 |

## 离线（val 30 状态 × 4 seeds）

| step | 总体 MAE | A90 抓取 MAE | B90 推动 cos | B90 Δz |
| ---: | ---: | ---: | ---: | ---: |
| 1000 | 0.0499 | 0.0480 | −0.122 | +0.0142 |
| 2000 | 0.0188 | 0.0167 | 0.453 | +0.0051 |
| 4000 | 0.0145 | 0.0145 | 0.575 | +0.0151 |
| 6000 | 0.0116 | 0.0105 | 0.353 | +0.0050 |
| 8000 | 0.0079 | 0.0074 | 0.708 | −0.0000 |
| **10000** | 0.0072 | 0.0072 | **0.750** | +0.0026 |
| 12000 | 0.0077 | **0.0069** | 0.640 | −0.0039 |

对照：AE 主实验 12k = 0.0070 / 0.0071 / 0.636 / −0.0005；
LoRA 12k = 0.0071 / 0.0069 / **0.826** / +0.0024。

**离线结论**：0.3×LR **消除了退化 checkpoint**（6000/8000 不再崩），
但**没有提高上限**：12k 与主实验基本一致，B90 cos 仍低于 LoRA。

## 训练初态闭环（18 条，与主实验同协议）

| 模型 | A90 | B90 | B90 advance 均值/中位 | B90 距墙 均值/中位 | 墙接触（中位） |
| --- | --- | --- | --- | --- | --- |
| AE 主实验 12k（1.0×LR） | 0/6（抬起 1） | 0/12 | 0.057 / 0.014 | 0.125 / 0.161 | 0 |
| AE 救援 4k（0.3×LR，欠训练） | 0/6 | 0/12 | 0.033 / 0.006 | 0.146 / 0.169 | 0 |
| **AE 救援 10k（0.3×LR，联合选中）** | 0/6（抬起 3） | **0/12** | **0.0137 / 0.0** | 0.165 / 0.176 | **0** |
| **LoRA 12k** | 0/6 | **1/12** | **0.127 / 0.170** | **0.052 / 0.0065** | 0 |

## 判读

1. 低 LR 让训练曲线变平滑（无 6000/8000 崩溃），说明**部分不稳定确实来自学习率**；
2. 但降低 LR **没有**改善闭环：救援 10k 的 B90 中位推进 0.0 m，比主实验 AE（0.014 m）更差，
   离 LoRA（0.170 m）更远；A90 也只是"抬起 3/6"但全部放置失败；
3. 因此"AE 不如 LoRA"不能归因为学习率过大——两条 LR 都指向同一结论；
4. 本实验不改变主结论，也不构成"AE 最优超参"的证据（未做逐参数调参）。
