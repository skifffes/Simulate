# 实验 0B：后继任务几何敏感性检查

本实验让 A 分别产生 z1/z2 两种终态，再执行位置、朝向都不同的 B/C 末端目标。每个条件使用 4 个关节初值做 IK，多起点结果先做限位检查，再做 80 段离散关节插值碰撞采样，路径通过后由原电机控制器执行。保留 direct 与 Reset-to-Canonical 对照。

这只是几何与控制器 sanity check，不是物体交接实验，也不是 VLA 组合泛化证据。路径碰撞检查是离散采样，不构成连续路径安全证明。重复运行确定性场景不等于独立统计样本。

运行：`python scripts/run_experiment_0b.py`。结果在本目录：`multistart_results.csv`（逐起点原始记录）、`summary.csv`、`comparison.png`、`config.json`（参数、种子、探索披露、旧 CSV SHA-256）。不覆盖原实验结果。

注意：每组 12 条是 3 个 IK 随机种子 × 4 个初始猜测，不是 12 次独立物理试验。物理环境未随机化，IK 初值含标准差 0.015 rad 的扰动。
以上成本是所有成功候选的均值，不是挑选最快候选；各候选从同一动力学快照独立执行。汇总 CSV 另有包含恢复动作的总成本。
HOME→C 的实际 tracking_error 原样保留。它表示当前控制器执行失败，不能推断目标物理不可达；失败组不报告成功成本，但原始 CSV 保留失败动作成本。
多起点仅检查交接状态附近 4 个初值，不是全局 IK 或路径规划证明。path_feasible 仅指当前碰撞检测器对 80 段插值的检查结果。
此前探索过多个 C 朝向及邻近位置，详见 config.json；本次是探索性结果，不是预注册确认实验。后续改变参数必须保留版本，不能只报告出现交叉的配置。
