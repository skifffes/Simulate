# Gate 1：专家动作经修复后 Action Adapter 的真实物理回放

问题：**不使用 π₀.₅，只把专家的控制目标经当前 Adapter 执行，Panda 能否复现专家的物理行为？**

- 数据：`exp4.1-split-v1` 的 **train** 段，A90 ep5/ep6、B90 ep0/ep1（不碰 test）。
- 初始状态：由采集记录 `start_object` + `goal_point` + `config_id`（含机器人启动构型）**精确恢复**。
- 评价器：`exp4.1-strict-v1.2`，与 4.2 闭环同一套。
- 一次跑三种对象：Reference（归档轨迹）、Replay A（专家原始目标直发）、Replay B（训练标签经 Adapter）。

## 判定

| 问题 | 答案 |
| --- | --- |
| 原始专家控制器能否完成任务？ | **能**：4/4 严格成功（A90 抬升/搬运/旋转/放置/释放；B90 真实触墙 669/922 个物理步）。 |
| 训练动作能否恢复原始专家控制目标？ | **能**：measured 锚点误差 5.6e-17 rad；recorded 锚点 2.5e-5 / 8.3e-3 rad。 |
| 修复后的 Adapter 能否物理复现专家主要运动与接触？ | **能**：物体位移、接触步数、墙面接触与专家回放逐项一致（上表）。 |
| 若不能，第一次偏离在哪？ | **本轮已不再是问题**；修复前（未加 horizon 缩放裁剪）第一次偏离出现在 **chunk 内 k=7**（A90 t=23，|T−E|=0.127 rad），根因是 0.25 rad 的逐步上限截断了累计偏移。 |
| 差异来自时间对齐/锚点/控制跟踪/物理状态？ | 修复后**四者都不再是误差来源**：q 跟踪到机器精度、锚点重锚正确、20 Hz×12 步一致、初始状态由采集记录恢复。 |
| 严格评价失败与历史标签版本有关？ | 本轮 4 条专家回放在 **v1.2** 下全部通过，说明 A90 的 45/45 历史标签与 v1.2 在本样本上一致；但历史 45 条仍保留 v1 标签来源（未逐条重判）。 |

## 对后续的含义

**执行链路（Adapter + 控制器 + 夹爪单位 + 频率 + 评价器）现在是可验证保真的**。
因此 4.2 闭环失败**不能再归因于执行契约**；剩余差异必须从模型的条件动作预测、
多步 chunk 一致性或数据监督本身去找（Gate 2/3 的结论）。
