# B90 ep1 与"垂直方向"诊断（1800 步模型）

数据：`rollouts_curve1800/*_substeps.csv` + `expert_state_curve1800.npz`
→ `approach_analysis.json`。回答两个补充问题：B90 ep1 为什么 0 接触；模型在专家状态上
是否学会了"保持/下降高度"。

## 1. B90 ep1：**横向（Y）偏了 7.3 cm，从方块旁边推空**

| 指标 | 数值 |
| --- | --- |
| EE–物体最小 3D 距离 | **0.077 m**（tick 9） |
| 最小距离处的 (dx, dy, dz) | (+0.005, **−0.073**, +0.025) m |
| EE 的 X 轨迹 | 0.406 → **0.708**（越过了方块） |
| 物体 X | 0.554 → 0.554（完全没动） |
| 接触 | 从未发生 |

→ ep1 不是"没推"，而是**从方块旁边（偏 7.3 cm）擦过去**；和 ep0（推着推着抬高 10.4 cm）是
两种不同的失败维度：一个是横向对齐，一个是垂直保持。

## 2. 专家状态上的 **Δz**：模型在接触/抓取阶段持续"往上走"

对 31 个唯一专家状态（4 seed）逐行算 `FK(q+Δq_model) − FK(q)` 与专家的同一量：

| 阶段 | 模型 Δz | 专家 Δz | 模型 Δx | 专家 Δx |
| --- | --- | --- | --- | --- |
| A90:approach | +0.0029 | −0.0050 | +0.0032 | +0.0018 |
| **A90:contact_onset** | **+0.0233** | −0.0000 | +0.0122 | 0.0000 |
| **A90:grasp** | **+0.0241** | **−0.0025** | +0.0090 | +0.0004 |
| B90:approach | −0.0048 | −0.0076 | +0.0081 | +0.0023 |
| **B90:contact_onset** | **+0.0148** | +0.0001 | +0.0259 | +0.0123 |
| **B90:push_pre_wall** | **+0.0201** | −0.0000 | +0.0158 | +0.0012 |
| **B90:wall_onset** | **+0.0212** | +0.0001 | +0.0093 | +0.0022 |
| **B90:wall_hold** | **+0.0203** | +0.0023 | +0.0043 | −0.0002 |

**规律**：接近段（approach）垂直方向没问题（B90 甚至略向下）；**一旦进入接触/抓取/推动，
模型每步向上 ~1.5–2.4 cm，而专家是 0（保持高度）或略向下**。

## 3. 统一解释（把 B90 与 A90 的失败串起来）

| 现象 | 由 Δz 偏差解释 |
| --- | --- |
| B90 ep0 推动 15.3 cm 后在 tick 23 失去接触 | 每 tick +2 cm 抬升 → 21 个 tick 后末端高出 10.4 cm，从方块上方滑过 |
| A90 两条都在方块上方 3.3–6.9 cm 徘徊、抓不到 | 抓取阶段每步 +2.4 cm 向上，无法下降到抓取高度 |
| B90 ep1 从旁边擦过 | 该失败是横向 Y 偏 7.3 cm（另一个维度），Δz 不是唯一原因 |

**结论**：模型已经学会"接近 + 方向 + 推进量"，但**没有学会接触状态下的高度约束**（Δz≈0）。
这正好是"状态约束"研究的第一手证据：接触后的状态（高度/法向）不被模型保持。

## 4. 下一步（不改表示、不加数据）

1. 2400 步训练后先看这张 Δz 表是否收敛（比看 loss 更有判别力）；
2. 若 Δz 仍为 +2 cm/step：说明是监督/覆盖问题，而不是训练量问题；
   届时可在离线诊断中统计训练数据里"接触阶段 Δz 分布"是否与自主状态匹配；
3. 闭环层面可以加"高度保持"检查（记录 dz 漂移），但**不引入专家辅助**。
