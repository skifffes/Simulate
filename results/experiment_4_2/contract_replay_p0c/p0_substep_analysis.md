## 4. 新的、更精确的诊断

1. **接近阶段方向是对的**：接触前命令 Δx 为正（+0.27 至 +0.66），实际 EE 也 +X（余弦 0.95–0.98）。
   这与"模型一直往 +Y 走"的旧表述不同，旧表述只看了首行/净位移。
2. **失败发生在接触阶段**：B90 ep00 一进入接触，命令立即变成 **−X（后退）且 +Y**，
   物体被推 +0.049 m 的 Y、X 几乎不动；A90 在接触的 9 个子步里命令接近 0/微负，
   夹爪没有真正闭合，随后 261 个子步"搬运空气"（+0.86 X 位移）。
3. **控制跟踪不是主因**：`q_track_err` 均值 0.015–0.066 rad，命令与实际 EE 余弦 0.84–0.98；
   （此前把 `final_q_vs_expert_state_max_err_rad≈1e-8` 误读为"控制器 1e-8 跟踪"，已更正为
   "专家回放的最终状态一致性"，真实跟踪误差见上表。）
4. **命令跳变合法**：最大 0.25 rad/周期，未触发 0.30 限速 → 之前的结果没有因动态跳变失真。

## 5. 判定

| 问题 | 答案 |
| --- | --- |
| 是"模型输出完整 chunk 就朝 Y"吗？ | **不是**。接触前命令是 +X；是**接触后**转为 −X/+Y。 |
| 是裁剪/限速改变方向吗？ | **不是**。拒绝 0 次、限速 0 次、`clipped_dims` 合计 0。 |
| 是控制器跟踪/动态吗？ | **次要**。跟踪误差 0.015–0.066 rad，余弦 0.84–0.98。 |
| 是 A→B 组合分布偏移吗？ | **不是**。B90 用训练条件（低 y 区目标 + home 构型），同一 prompt/相机。 |

→ 剩余主因是**接触阶段的条件行为**（模型在"刚接触方块"的状态下不会持续推/不会正确闭合），
属于模型学习问题，不是执行链路问题。这解释了为什么修好三项契约、把 `execute_k` 降到 1 仍然失败。
