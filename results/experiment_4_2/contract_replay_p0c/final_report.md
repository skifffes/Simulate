## 4. 八个问题

**Q1. 修复后的 Action Adapter 能否准确复现专家控制目标？**
`OBSERVED` **能**。measured 锚点 5.6e-17 rad；recorded 2.5e-5 / 8.3e-3；单测 12/12。

**Q2. 专家动作经同一 Adapter 连续执行后，能否复现关键接触与运动阶段？**
`OBSERVED` **能**。8/8 回放严格成功；A90 接触步 997–1010，B90 墙面接触 669/922，与专家一致。

**Q3. 如果专家回放失败，第一处偏差在哪？**
`OBSERVED` 修复前在 chunk 内 k=7（A90 t=23，目标差 0.127 rad），根因是 0.25 上限截断累计偏移；
修复后无偏差（1e-17）。

**Q4. B90 的 +Y 推动主要来自模型 EE 方向，还是错误接触几何？**
`OBSERVED` **模型命令路径**：接近阶段 +X 正确（命令路径 +0.186）；
首次接触发生在"接触前生成的 chunk"里（开环，2 个子步）；**接触之后**模型先退开
（无接触段 −0.294），再以 +Y 为主重新靠近（接触内 +0.191 Y），方块只得到 +0.050 Y。
接触几何 `CONTRADICTED`（专家同场景 (+0.177, −0.000)）。
（初版"接触期后退 0.343"是目标偏差误当路径，已作废。）

**Q5. HOME 静止阶段是有意义的监督、不可观测的等待，还是采集伪影？**
`OBSERVED` 首步监督 `VALID`（首行一致为 0）；chunk 后续行 `AMBIGUOUS`（同一观测→差 0.16–0.19 rad）；
6 帧等待是采集伪影（`_settle(0.3)`，90/90 条都在第 6 帧）。

**Q6. 当前最重要的剩余问题是模型学习、时间标签、动作尺度，还是执行控制？**
OBSERVED（第三轮补充）：同一条 anchor-16 轨迹上，模型幅度随训练量单调下降
（300 步 0.52 rad → 600 步 0.24 → step901 900 步 0.11），方向余弦仍近 0；
过拟合 8 窗口可到 0.025 rad（loss 0.0064）→ **失败是学习效率/训练量问题，不是 pipeline 或表示**。
真·主动推动帧（8 帧）上 step901 仍是 3.2× 偏大、余弦 0.18。
`OBSERVED`（新增证据，`expert_state_diagnostic.md`）：**在专家自己的观测上**，模型首行动作
仍为 0.11–0.41 rad，而专家是 0.0008–0.04 rad（B90 3–61×、A90 最多 1411×），
种子间 std 仅 0.02–0.08 → **bias 远大于 variance**，方向余弦多为 0.06–0.46（A90 抓取为负）。
所以"条件动作学习不足"是直接观测到的，不是从闭环失败反推的。
`SUPPORTED`：**模型在接触后/接触时的条件行为**（学习问题），但"是与否"仍与动作表示耦合：
anchor 与 target_increment 在归一化空间的跨度差 **0.175–0.761 vs 0.023–0.057**，
这本身就是 Gate 4 要分离的变量。
执行控制 `CONTRADICTED`（命令路径 ≈ 实际路径）；动作尺度 `WEAKENED`（anchor 下 17.5–76%、clip=0）；
时间标签在首步 `VALID`、chunk 行 `OBSERVED-AMBIGUOUS`。

**Q7. 静止窗口加权（P0c）与 normalization 单变量对照是否应开展？为什么？**
`NOT STARTED`，两者都不满足启动条件：
1. 静止段：首步监督已明确、chunk 行有结构性歧义，过采样会放大歧义（Gate 3 已证）；
2. **normalization**：真实训练标签跨度 17.5–76%、clip 比例 0、往返 1e-16 →
   "信号被压窄"的前提不成立，300+300 对照预期无差异，**不开展**；
3. 两条硬门槛（"确认无更基础错误"与"离线有清楚信号"）都未满足。

**Q8. 下一次最值得进行的单变量研究干预是什么？**
`HYPOTHESIS` 推荐（细节见 [`gate4_preflight.md`](gate4_preflight.md) §7）：

1. **动作表示单变量**：A=`anchor`+`fixed`，B=`target_increment`+`recursive`，各 300 **实际 optimizer update**，
   同 base/LoRA/数据序/随机源/horizon16/DROID stats/32D loss/安全阈值。
   两者在 Gate 1 里都已验证能精确重建专家命令（4/4、目标误差 0 / 5.6e-17），
   所以差异只能来自模型学到的目标分布；
2. 结论只能表述为"**表示及其目标分布的联合效果**"（跨度 0.175–0.761 vs 0.023–0.057），
   不能归因于"DROID 先验"；
3. `observed_residual` 不参与本轮（递归重建误差 0.379 rad），若要测必须配 `execute_k=1` 独立进行；
4. 若表示对照无可分差异 → **horizon 16→4**；再不行才考虑接触阶段重采样（需先给数据打接触标签）。

不建议：继续加训练步数；静止窗口加权；不改表示的前提下再调 LR/归一化。


### 第四轮（1200 步曲线 + 闭环）更新

- **训练量/学习率相位已证实是主导变量**：同一条 anchor-16 轨迹上 300/600/900/1200 updates，
  幅度 0.52→0.24→0.07→0.06 rad；方向余弦在越过 warmup（1000 步）后跃升（approach 0.26→0.80、
  contact_onset 0.48→0.83）；整段 MAE 0.059→0.034、物理目标最大误差 0.59→0.30 rad。
- 因此此前"动作表示无可分效应"的结论**作废**（300 步 = 0.48 epoch、LR≈30% 峰值），
  表示对照必须在 ≥1200 步重做。
- 1200 步模型的闭环仍 0/4，但 B90 机器人-方块接触从 7 个物理步升到 **845** 个、advance 仅 0.015 m；
  `execute_k=1` 反而 0 接触 → 不是"多步累积"单一原因，而是接触期的方向/时序仍不够准。
- 下一步（按优先级）：①1200→1800/2400 继续训练并记录 LR 与离线曲线；②在 1200 基线上做接触期
  "专家动作 vs 模型动作"配对（方向/力度）；③表示对照推迟到 ≥1200 步。
