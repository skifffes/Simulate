## 1. Gate 0/1 的核心：第三个契约缺陷

修好"锚点递归累加"和"夹爪单位"后，专家回放仍然 2/4 失败，teacher-forced 误差 0.30–0.54 rad。
本轮定位到：`max_delta_rad = 0.25` 是按**每步增量**设计的，但固定锚点下 `a_k` 是**跨 k+1 步的累计偏移**，
A90 旋转阶段第 8 步的 0.31 rad 合法偏移被截断。
修复：固定锚点下第 k 步上限取 `(k+1) × 0.25`（recursive 保持原样，4.0 归档不变）。

修复后（`expert_replay_results.csv`）：

- A90 ep5/ep6：adapter 回放 **严格成功**，q 跟踪 7.7e-08 / 8.2e-08 rad，物体位移与接触步与专家**逐项相同**；
- B90 ep0/ep1：adapter 回放 **严格成功**，墙面接触 669 / 922 个物理步，与专家完全相同；
- teacher-forced 目标误差 **5.6e-17 rad**（measured 锚点）/ 2.5e-5、8.3e-3（recorded 锚点）。

→ **执行链路（Adapter + 控制器 + 夹爪 + 频率 + 评价器）现在是可验证保真的**。
4.2 闭环失败不能再归因于执行契约。

## 2. Gate 2：B90 的 +Y 从哪来

→ **模型的 EE 运动本身就偏 +Y**（接触期和整段都是），物体 +Y 是接触的结果；
不是接触几何、不是执行链路、也不是单纯的多步漂移。

## 4. 八个问题

**Q1. 修复后的 Action Adapter 能否准确复现专家控制目标？**

**Q2. 专家动作经同一 Adapter 连续执行后，能否复现关键接触与运动阶段？**
`OBSERVED` **能**。4 条 episode × 两种锚点 = 8 次回放**全部严格成功**；
A90 抬升/搬运/旋转/放置/释放接触步 997–1010，B90 墙面接触 669/922，与专家回放一致到 1–2%。

**Q3. 如果专家回放失败，第一处偏差在哪？**
`OBSERVED` 修复前第一处偏差在 **chunk 内 k=7**（A90 t=23，目标差 0.127 rad），
根因是 0.25 rad 的逐步上限截断累计偏移；修复后不再有偏差（`OBSERVED`：误差 1e-17）。

**Q4. B90 的 +Y 推动主要来自模型 EE 方向，还是错误接触几何？**
`OBSERVED` **模型 EE 方向**。接触期模型 EE Δy=+0.072 而专家 −0.000（同场景同接触几何）；
`execute_k=1` 仍 +Y。接触几何假设 `CONTRADICTED`。

**Q5. HOME 静止阶段是有意义的监督、不可观测的等待，还是采集伪影？**
`OBSERVED` **首步监督有意义**（t=0..5 首行标签一致为 0），但 **6 帧等待是采集伪影**（`_settle(0.3)`）；
chunk 后续行 **不可识别**（同一观测 → 不同未来，差 0.16–0.19 rad）。
即：`VALID`（首步）+ `AMBIGUOUS`（chunk 行）+ `ARTIFACT`（6 帧时长）。

**Q6. 当前最重要的剩余问题是模型学习、时间标签、动作尺度，还是执行控制？**
`SUPPORTED`：**模型的条件多步方向**是首要问题（执行控制 `CONTRADICTED`）；
时间标签在**首步**没问题、在**chunk 行**存在结构性歧义（`OBSERVED`）；
动作尺度是并存的 `HYPOTHESIS`（train/DROID 跨度比 0.024–0.061，未做单变量反事实）。

**Q7. 静止窗口加权能否改善启动行为、同时保持运动能力？若未开展训练，为什么不应开展？**
`NOT_IDENTIFIABLE`（未训练）。不开展的理由：
1. Gate 3 显示首步监督**已经明确**，模型学错不是"没看到静止样本"；
2. 静止段的 chunk 后续行**存在结构性歧义**，过采样会放大这个歧义；
3. Gate 2 已定位主要错误在**运动中的 +Y 方向**，静止加权不针对它；
4. 硬门槛"静止监督可学习且采样不足"未被满足（首步行 VALID 但非采样量问题）。
→ 按 prompt §六/§八的停止规则，**不启动 P0c 训练**。

**Q8. 下一次最值得进行的单变量研究干预是什么？**
`HYPOTHESIS` 建议按优先级：
1. **动作尺度单变量反事实**（只改归一化：train-split stats 或对 Δq 重标定，训练/推理同步、版本化）；
   它直接针对"模型输出幅度/方向分布在 normalized 空间被压窄"的假设，且不改数据、不改结构；
2. 若尺度无效：**缩短 action horizon（16→4）**，把"多步歧义"从监督里移除（单变量，但需重训）；
3. 最后才考虑给输入加阶段/时间标量（改契约，需训练+推理同步）。
不建议再加训练步数，也不建议在静止窗口上做采样加权。
