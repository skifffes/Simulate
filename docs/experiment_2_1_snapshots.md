# 实验 2.1 · 阶段 2：真实交接状态快照与恢复验证

## 1. 做了什么

用**冻结的 SmolVLA** 重新执行 A0、A90 各 20 个测试 episode（种子 `40000000–40000019`），在 A 真实成功且物体稳定后保存完整状态快照；再用独立进程恢复每个快照并逐项比对。

- 没有专家参与，没有修改物体，没有重置机器人。
- A 成功的必要条件：抬升 ≥3 cm、自主释放、物体在放置区 2 cm 内、朝向误差 ≤12°、倾角 ≤12°、静置 1.0 s 后连续 5 次速度 <0.01 m/s。
- 40 个 episode 全部成功并保存（A0 20/20、A90 20/20），抬升 0.118–0.127 m。

## 2. 快照内容

每个快照包含三部分（共 40 组）：

| 文件 | 内容 |
|---|---|
| `A{0,90}_<seed>.bullet` | PyBullet 完整世界状态（`saveBullet`） |
| `A{0,90}_<seed>.json` | 机器人/物体/观测/指令等结构化状态 |
| `A{0,90}_<seed>_top.png`、`_wrist.png` | 保存时刻的两路 RGB |

JSON 里的字段：

- **机器人**：7 关节角、7 关节速度、末端位姿、双指位置与速度、各关节到上下限的距离。
- **物体**：位置、四元数、线速度/角速度、yaw、倾角。
- **接触**：双指接触数、与桌面的接触数。
- **观测**：策略实际收到的 9 维本体状态、两路图像。
- **动作**：最后一条策略动作（7 关节目标 + 夹爪目标）。
- **上下文**：技能名、当前指令、计划中的后继技能、episode 种子、控制周期、抬升高度、释放 tick。

## 3. 恢复验证

独立进程里用同一 seed 重建场景 → `restoreState(.bullet)` → 与保存值比对 40 次：

| 指标 | 结果 |
|---|---|
| 关节角最大偏差 | **0.0**（全部 40 个） |
| 双指位置最大偏差 | **0.0** |
| 物体位置偏差 | **0.0 m** |
| 物体四元数偏差 | **0.0 rad** |
| 双指接触数差 | **0** |
| 两路图像 MAE | **0.000** |

40/40 通过。结论：**快照可以在新进程里逐位复现保存时刻的物理与视觉状态**。

产物：`results/experiment_2_1/snapshots/restore_check.json`。

### 限制

`restoreState` 恢复的是刚体/关节状态，接触求解器的内部历史（warm-start 缓存）不会被保存。恢复瞬间的位姿、接触与图像完全一致，但恢复后继续仿真时，求解器从冷启动开始，长时间 rollout 可能与原始轨迹有细微分叉。阶段 3 会用 T0 重放与实验 2 的真实组合结果对照，量化这一影响。

## 4. A0 / A90 终态差异

| 量 | A0（20 次） | A90（20 次） |
|---|---|---|
| q1 | 0.339 ± 0.004 | 0.573 ± 0.004 |
| q2 | 0.587 ± 0.006 | 0.605 ± 0.005 |
| q3 | −0.028 ± 0.004 | −0.245 ± 0.003 |
| q4 | −2.088 ± 0.005 | −2.079 ± 0.003 |
| q5 | 0.032 ± 0.004 | 0.297 ± 0.004 |
| q6 | 2.678 ± 0.005 | 2.656 ± 0.006 |
| **q7（腕）** | **−0.509 ± 0.013** | **0.898 ± 0.018** |
| 最近关节限位余量 | 1.046 rad | 1.057 rad |
| 物体位置 | (0.552, 0.183) | (0.557, 0.179) |
| 物体 yaw | 0.9° ± 1.0° | −90.4° ± 1.6° |

三个直接结论：

1. **A0 与 A90 的机器人构型差异主要在第 7 关节（1.41 rad ≈ 81°）**，另有 q1/q3/q5 约 0.22–0.26 rad 的差别。
2. **没有任何关节接近限位**（最小余量 >1 rad），所以 A90→C 的失败不能归因于"关节到限位了"。
3. **物体位置几乎相同**（差 <5 mm），只有 yaw 差 90°。因此在 T1/T2 对照中，位置因素基本被排除，主要变量是腕部构型与物体朝向。

## 5. 对阶段 3 的意义

- T0（真实交接）可以直接用快照恢复，保证与真实组合状态一致。
- T1（机器人 HOME + 物体 A 终态）只改 7 个关节角，物体、相机、指令不变；由于 B/C 的训练起点就是 HOME，这组直接检验"构型偏移"假设。
- T2（机器人 A 终态 + 标准物体）把物体重置到 `PLACE + yaw 0`，用于分离物体朝向/视觉因素。
- T3（HOME + 标准物体）等价于原子评测的标准起点，作为上限对照。

所有 T1/T2/T3 的构造都要先做有效性检查：关节限位、机器人-物体穿插、物体与桌面接触、静止。

## 6. 复现

```bash
cd ~/simulate_vla
# 采集快照（约 20 分钟）
HF_HUB_OFFLINE=1 CUDA_VISIBLE_DEVICES=3 PYTHONPATH=src venv/bin/python \
  scripts/collect_handoff_snapshots.py --skills A0 A90 --episodes 20 \
  --out results/experiment_2_1/snapshots

# 恢复验证（约 2 分钟）
PYTHONPATH=src venv/bin/python scripts/verify_snapshot_restore.py \
  --snapshots results/experiment_2_1/snapshots \
  --out results/experiment_2_1/snapshots/restore_check.json
```
