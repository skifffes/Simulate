# 实验 2：多原子技能共享 VLA 与零样本技能组合

## 摘要

本轮用 480 条独立原子示范（A0 / A90 / B / C 各 120）微调了**一个共享 SmolVLA**，并在严格自主口径下评测了四类原子技能与四条未见组合链。

| | 结果 |
|---|---|
| 原子技能（20 集/类） | A0 **100%**、A90 **100%**、B **40%**、C **95%**（专家 100 / 100 / 90 / 95） |
| 组合：A0→B | **0/20** |
| 组合：A90→B | **0/20** |
| 组合：A0→C | **20/20** |
| 组合：A90→C | **0/20** |

最关键的发现：**原子技能会做，不等于组合会做**。C 单独执行 95%，在 A90 之后掉到 0%；B 单独 40%，在 A 之后也掉到 0%。而 A0→C 是 100%——说明链路本身是通的，失败来自**交接状态分布偏移**，不是"模型不会 C"。

## 1. 实验设置

- 场景、坐标系、A0/A90 定义、挡板与托盘：见 [docs/experiment_2_scene.md](experiment_2_scene.md)。
- 数据：480 集 / 68 808 帧 / 4 任务，见 [docs/experiment_2_data.md](experiment_2_data.md)。
- 训练：共享 SmolVLA，20 000 步，见 [docs/experiment_2_training.md](experiment_2_training.md)。
- 测试种子 `40000000–40000019`，与采集种子（900 000+）完全隔离。
- 严格口径：判定前不替模型张爪、不修正末端、不移动物体；成功来自真实物体状态。
- 组合评测用 Oracle Scheduler：真实状态判断 A 完成 → 切换到 B/C 的语言指令 → `policy.reset()` 清空旧动作块。A 与后继在**同一 episode** 内连续执行，中间不重置。

## 2. 原子技能结果

| 技能 | VLA | 95% CI | 专家 | 说明 |
|---|---:|---|---:|---|
| A0 | **20/20 (100%)** | 84–100% | 20/20 | 保持长轴 Y |
| A90 | **20/20 (100%)** | 84–100% | 20/20 | 搬运中旋转 90° |
| B | **8/20 (40%)** | 22–61% | 18/20 (90%) | 推动 |
| C | **19/20 (95%)** | 76–99% | 19/20 (95%) | 抓起并放入托盘 |

推理延迟约 11 ms / 控制周期（20 Hz 预算 50 ms）。

**B 的失败集中在"推不稳"**：8 次失败里多数已经把物体推到墙边（前缘间隙 ≤1 cm），但推动过程中物体 yaw 变化 18°–100°，超过 15° 阈值；另有 1 次只推到距墙 4 cm。没有出现"完全不碰物体"的失败——模型确实在推，只是接触点偏、把物体推转了。

## 3. 组合结果

| 组合 | 整链成功 | A 成功 | A 成功后后继成功 | 条件成功率 |
|---|---:|---:|---:|---:|
| A0→B | 0/20 | 20/20 | 0/20 | 0% |
| A90→B | 0/20 | 20/20 | 0/20 | 0% |
| A0→C | **20/20** | 20/20 | 20/20 | **100%** |
| A90→C | 0/20 | 20/20 | 0/20 | 0% |

A 本身在组合里 80/80 全成功（A0 平均 99 tick，A90 平均 141 tick），说明失败全部发生在**交接之后**。

### 3.1 终态证据

| 组合 | 物体最终位置 | 含义 |
|---|---|---|
| A0→C | (0.545, 0.396)，yaw≈0 | 正确进入托盘 |
| A90→C | (0.556, 0.25)，yaw≈−1.35 rad | 只移动了约 7 cm，没有被抓进托盘：**抓取/搬运段失败** |
| A0→B | z≈0.07–0.08 m，yaw≈−1.3 rad | 物体被**举到空中**，不是被推：模型在交接后重新抓起了物体 |
| A90→B | z≈0.08–0.09 m | 同上 |

这是本轮最有信息量的诊断：**组合失败不是"动作不够好"，而是后继技能在交接状态下执行了错误的动作模式**——B 在 A 之后变成了"抓起"，C 在 A90 之后抓不住旋转后的物体。

## 4. 对研究问题的回答

**Q1. 共享 SmolVLA 是否真正学会了 A0、A90、B、C？**
部分学会。A0/A90/C 达到或接近专家水平（100/100/95），B 只有 40%（专家 90%）。B 是明显的原子学习短板。

**Q2. 各原子技能成功率？**
A0 100%、A90 100%、B 40%、C 95%；专家对照 100/100/90/95。

**Q3. 以 A 的真实终态作为 B/C 起点，成功率是否下降？**
会，而且高度依赖技能与交接状态：C 在 A0 之后不降反升（95%→100%），在 A90 之后从 95% 掉到 0%；B 在 A 之后从 40% 掉到 0%（两种 A 都是）。所以不是"组合一定掉"，而是**某些交接状态严重越界**。

**Q4. A90 是否真的更适合后续的 B？**
没有证据。A0→B 与 A90→B 都是 0/20。阶段 1 专家数据里"A90 推短端面 yaw 扰动更小（0.6° vs 4.9°）"的倾向没有在 VLA 链路上体现——因为 B 在交接后根本没在推。

**Q5. A0 是否真的更适合后续的 C？**
是，而且非常明显：A0→C 20/20，A90→C 0/20。

**Q6. A90 的额外旋转成本是否被后续收益抵消？**
没有。A90 本身多花约 42 个控制周期（141 vs 99），且 A90→C 全败、A90→B 也全败；本轮没有任何组合收益可以抵消它的成本。

**Q7. 组合失败主要来自哪里？**
**交接状态偏移**，具体是机器人构型与物体姿态的组合，而不是单纯的视觉定位或原子能力：
- B 的示范全部从 HOME 出发、从侧面接近物体；A 结束后夹爪已经在物体正上方且张开，模型在这种状态下输出的是"闭合 + 抬起"（A 的动作模式），不是"推"。
- C 的示范覆盖了长轴 Y 与长轴 X 两种物体朝向，但机器人始终从 HOME 出发；A90 结束时腕部已经旋转 −90°，C 在这种构型下抓不住物体。

**Q8. 当前实验是否构成有价值的 Plan-Conditioned 测试场景？**
是。它给出了一个可复现、可解释的交叉结果（A0→C 100% vs A90→C 0%），并证明原子成功率不能预测组合成功率。但目前 B 的原子能力太低，A→B 两组全 0，信息量有限；需要先把 B 做好或把交接状态纳入训练分布。

**Q9. 下一轮是否值得测试 Next-Skill Conditioning、Flow Fusion 或 Boundary Inpainting？**
值得，但优先级应排在"修数据分布"之后。当前 0% 的组合失败来自后继技能没见过交接状态，这类问题**靠改生成方法解决不了**。建议顺序：
1. 提高 B 的原子成功率（更多示范 / 推动阶段专门增强）；
2. 采集 B/C 示范时**随机化机器人初始关节构型**，覆盖 A 终态附近的构型（仍是独立原子示范，不引入 A→B 轨迹，不违反泄漏约束）；
3. 再比较直接切换、Next-Skill Conditioning、Boundary Inpainting——那时若仍有明显差距，才是方法本身的贡献。

## 5. 失败原因分类（组合）

| 组合 | 主要失败模式 | 判定依据 |
|---|---|---|
| A0→B | 交接后把物体抓起而非推动 | 终态 z≈0.07–0.08 m |
| A90→B | 同上 | 终态 z≈0.08–0.09 m |
| A90→C | 抓取/搬运失败，物体只移动约 7 cm | 终态仍在放置区附近、yaw 未转回 |
| A0→C | 无失败 | 20/20 |

## 6. 局限

- 每个原子技能 20 集、每个组合 20 集，置信区间仍然较宽（尤其 B 的 40% 是 22–61%）。
- 只有 15 000/20 000 步的单个训练预算，没有做 checkpoint 选择（本轮直接用 20K）。
- B 的失败阈值（yaw ≤15°）沿用了阶段 1 的设定，没有针对推动任务单独标定。
- 组合只测了 A→B / A→C 四种，没有 B→A、C→A 等顺序。
- 没有对 A90→C 的抓取段做逐 tick 诊断（当前只记录终态），下一轮应补阶段事件。

## 7. 复现

```bash
# 原子评测
CUDA_VISIBLE_DEVICES=3 HF_HUB_OFFLINE=1 PYTHONPATH=src venv/bin/python \
  scripts/eval_multi_atomic_vla.py \
  --policy outputs/smolvla_multi/checkpoints/020000/pretrained_model \
  --skills A0 A90 B C --episodes 20 --seed-base 40000000 \
  --out results/experiment_2/eval_atomic

# 组合评测
CUDA_VISIBLE_DEVICES=3 HF_HUB_OFFLINE=1 PYTHONPATH=src venv/bin/python \
  scripts/eval_skill_composition.py \
  --policy outputs/smolvla_multi/checkpoints/020000/pretrained_model \
  --chains A0_B A90_B A0_C A90_C --episodes 20 --seed-base 40000000 \
  --out results/experiment_2/eval_composition

# 汇总
python scripts/analyze_experiment_2.py
```
