# 实验 0C 第一阶段：真实接触下的抓取、抬升、移动与放置

本轮只做 A 的共同任务本身：**接近 → 电机闭合夹爪 → 抬升约 10 cm → 移动 → 放下 → 释放**。B/C 后继交接、VLA 与 RL 均未实现，也不在本次结论范围内。

## 1. 范围与不变式

- 工件是可自由移动的长方体（`useFixedBase=False`），不是 0B 里那个固定立方体。
- 抓取、抬升、运输、放置全部由 Panda 双指夹爪的**真实接触**完成。
- `resetBasePositionAndOrientation` 只在每次 episode 开始时把工件摆到固定起点，运行过程中从不调用。
- 没有创建固定约束、没有设置 kinematic、没有把工件焊到夹爪上。
- 物体的运动只可能来自接触力和重力；可由 `trajectory.csv` 中的 `obj_*` 列逐步核对。
- 0B 的代码、数据和结论未被覆盖。工件使用独立的 `Simulation(reference_cube=False)`，0B 仍默认加载原来的固定参考立方体。

## 2. 场景与关键尺寸

| 项目 | 数值 |
|---|---|
| 工件 | 0.04 × 0.04 × 0.08 m 长方体，质量 0.12 kg |
| 工件摩擦 | lateral 1.2，spinning 0.05，rolling 0.01，restitution 0 |
| 初始位姿 | 中心 `(0.55, 0, 0.041)`，底面离桌 1 mm |
| 桌面 | `plane.urdf`（z = 0） |
| 夹爪 | Panda 原有双指，两个 prismatic 关节（link 9/10） |
| 手指行程 | 每指 0~0.04 m，总开口 0~0.08 m |
| 手指最大力 | URDF 限制 20 N/指，本实验全部按上限驱动 |
| 抓取姿态 | 夹爪 z 轴朝下，两指沿世界 y 轴开合 |
| 抓取点 | 末端目标 `(0.55, 0, 0.055)` |
| 抬升量 | 末端抬到 `z = 0.155`，即抬升 0.10 m |
| 放置点 | `(0.45, 0.18, 0.055)` |

**为什么抓取高度是 5.5 cm。** 朝下姿态下实测：指尖在末端目标上方约 1.1 cm，手掌（link 8）碰撞盒底部在末端目标上方约 3.5 cm。工件顶面在 `z = 0.08`，所以需要

- 指尖插入工件：`ee < 0.08 + 0.0112`，取 0.055 时指尖在 0.0438，插入 3.6 cm；
- 手掌不碰工件顶面：`ee + 0.035 > 0.08`，取 0.055 时手掌底在 0.090，留 1 cm 净空。

早期直接把末端目标设到工件中心（`z = 0`）时，手掌碰撞盒压到工件顶面，接触力达 298 N 并把工件推开 1.4 cm；这是**几何摆放错误**，不是摩擦或求解器问题。

## 3. 控制流程

| 阶段 | 动作 | 时长（仿真秒） |
|---|---|---:|
| `open_gripper` | 两指张开到 0.04（开口 8 cm） | 0.50 |
| `approach_pre` | IK + 关节插值到工件上方 `(0.55, 0, 0.18)` | 1.35 |
| `preclose` | 预闭合到 0.024（开口 4.8 cm，比工件宽 8 mm） | 0.60 |
| `approach` | 垂直到抓取高度 `z = 0.055` | 0.65 |
| `close` | 电机目标 0.017，被工件挡住后建立 20 N/指 夹持力 | 0.80 |
| `lift` | 末端抬到 `z = 0.155` | 0.57 |
| `transport` | 平移到放置点上方 `(0.45, 0.18, 0.155)` | 0.84 |
| `lower` | 垂直到 `z = 0.055` | 0.64 |
| `release` | 张开到 0.04，工件落到桌面 | 0.80 |
| `retreat` | 抬到 `z = 0.24` 撤走 | 0.93 |
| `settle` | 等待 1.0 s 后测速度与位姿 | 1.00 |

预闭合是为了减少"从 8 cm 开口直接闭到 4.4 cm"的空行程冲击。若先张开再下降、最后才闭合，手指会以较大速度撞上工件侧面，把 4 cm 宽的工件推开，实测中曾直接导致抓空。

## 4. 成功判定

只看物体与接触，不把"机械臂到达目标"当作成功：

| 判定 | 阈值 |
|---|---|
| 双指接触 | `close` 结束后 link 9 与 link 10 都有非零法向力 |
| 抬升高度 | 抬升阶段物体 z 增量 ≥ 0.08 m（目标 0.10 m） |
| 相对滑移 | 物体在夹爪坐标系中的位移 ≤ 0.02 m |
| 手掌/臂碰撞 | 工件与 link 8 及臂本的接触采样数必须为 0 |
| 放置位置 | 释放并静置后，物体 xy 与目标差 ≤ 0.02 m |
| 放置高度 | 物体中心 z 与半高（0.04 m）相差 ≤ 0.012 m |
| 姿态 | 物体局部 z 轴倾角 ≤ 12° |
| 静置 | 静置结束时线速度 ≤ 0.01 m/s 且角速度 ≤ 0.10 rad/s |
| 释放 | 撤离后工件与夹爪的接触点数 = 0 |

任一不满足即失败，并写入 `failure` / `failure_stage` / `failure_text`。

## 5. 结果

### 5.1 固定场景重复（5 次）

输出：`results/experiment_0c/`

| 指标 | 值 |
|---|---:|
| 成功 | 5/5 |
| 抬升高度 | 0.1000 m（5 次完全相同） |
| 双指接触力 | 20.00 N / 20.00 N（电机上限饱和） |
| 相对滑移 | 3.45 mm |
| 放置 xy 误差 | 2.83 mm |
| 放置高度误差 | −0.01 mm |
| 终态倾角 | 0.0003° |
| 终态线速度 | 1.2e-10 m/s |
| 释放后接触 | 0 |

5 次结果逐位相同，因为场景与初值完全一致、PyBullet 是确定性求解器。这证明**同一固定场景可重复**，但**不是**独立物理试验，也不能当作鲁棒成功率。

### 5.2 初始位置扰动（±4 mm、±0.1 rad，5 次）

输出：`results/experiment_0c_jitter/`。工件起点随机平移 ±4 mm、绕竖轴 ±0.1 rad，抓取点跟随工件（模拟已经定位），其余流程不变。

| 指标 | 值 |
|---|---:|
| 成功 | 5/5（平均偏移 3.5 mm） |
| 抬升高度 | 0.1000 m |
| 相对滑移 | 4.08 mm |
| 放置 xy 误差 | 3.55 mm |

### 5.3 负对照：摩擦与夹持力扫描（16 组）

输出：`results/experiment_0c_diagnose/grid.csv`。只改工件摩擦和夹爪电机力上限，其余完全一致。

| μ \ 力 | 0.5 N | 2 N | 8 N | 20 N |
|---|---|---|---|---|
| 0.05 | 失败 | 失败 | 失败 | 成功 |
| 0.20 | 失败 | 失败 | 成功 | 成功 |
| 0.60 | 失败 | 成功 | 成功 | 成功 |
| 1.20 | 失败 | 成功 | 成功 | 成功 |

共 9/16 成功，失败全部报 `object_not_lifted`，且抬升阶段滑移达到 0.10 m（工件落回桌面）。这组对照说明：

1. 成功确实来自摩擦与夹持力，不存在隐藏约束；
2. 失败检测器在真实失败时能报出正确原因，不是恒为 `True`；
3. 该工件需要约 8 N 以上夹持力或 0.6 以上摩擦才能稳定抬起，与 0.12 kg × 9.81 的重力一致（0.5 N/指 时摩擦不足）。

## 6. 失败原因码

| 代码 | 含义 |
|---|---|
| `grasp_no_contact` | 闭合后双指没有同时接触 |
| `hand_contact` | 工件碰到手掌或臂本 |
| `object_not_lifted` | 抬升后物体没被带起 |
| `object_slipped` | 运输中相对滑移超限 |
| `place_position_error` / `place_height_error` | 放置位置/高度超差 |
| `object_tipped` | 释放后倾角过大 |
| `object_unstable` | 静置后仍在动 |
| `not_released` | 释放后仍与夹爪接触 |
| `collision_during_motion` / `tracking_error` / `ik_joint_limits` | 来自 `RobotController` 的运动层失败 |

注意：`Simulation.allowed_contacts` 只放行**手指 link 9/10 与工件**的接触；手掌、前臂与工件的接触仍然算碰撞，不会被静默忽略。

## 7. 局限

- 单工件、单场景、无视觉、无传感器噪声；抓取点直接使用已知的工件位姿。
- 确定性重复不等于独立物理样本，成功率 5/5 不能外推为鲁棒性指标。
- 放置精度 2.8 mm 来自仿真内的稳定接触求解，不代表真机精度。
- 夹持力 20 N 是 URDF 上限，现实 Panda 可以更大；本实验刻意不超限。
- 没有实现 B/C 后继交接，也没有实现阶段二的物理交接实验。
- 没有做连续碰撞检测，快速运动仍可能穿透薄几何。
