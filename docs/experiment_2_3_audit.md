# 实验 2.3 阶段 0：现有数据、起点覆盖与评测协议审计

## 摘要

在开始多起点数据实验之前，先核对实验 2 / 2.1 / 2.2 的原始产物与代码。结论有四条，直接影响 2.3 的数据设计：

1. **B/C 的训练起点确实是单一 HOME**：480 集数据里，四个技能的起始七关节构型唯一值都是 **1 行**，与 HOME 的最大偏差 **1.39×10⁻⁵ rad**。数据里没有任何机器人起点多样性。
2. **B 的原子瓶颈与物体朝向强相关，而不只是"推不稳"**：冻结 SmolVLA 在 B 上总成功率 40%，但按初始 yaw 拆开是 **yaw≈0°（长轴 Y）1/12 = 8%**、**yaw≈90°（长轴 X）7/8 = 88%**；专家在同种子下是 10/12 与 8/8。所有失败都是 `push_check`（物体被推转或没贴到墙）。
3. **A 的真实终态离 HOME 很远**：A0 终态距 HOME **2.00 rad**、A90 **1.65 rad**；而 B/C 示范的起点只覆盖 HOME。所谓"交接状态越界"在起点分布上是可量化的。
4. **2.2 的评测协议与退让实现是自洽的**：后继技能统一用 v2.2 判据（到达后停发动作、静置 1.0 s、再复核）；物理退让是 0.002 rad/步的连续关节运动，不调用 `resetJointState`，80/80 走直接路径。

因此，2.3 如果只"把机器人起点打散"，会同时改变机器人构型与（若不小心）物体 yaw 分布；**必须把 yaw 作为独立分层变量**，否则无法判断收益来自起点多样性还是更容易推的物体朝向。

## 2. 起点覆盖：只有 HOME

来自实验 2.1 对 480 集首帧 `observation.state` 的审计：

| 技能 | 起始关节唯一行数 | 与 HOME 最大偏差 (rad) | 起始夹爪均值 |
|---|---:|---:|---:|
| A0 | 1 | 1.39×10⁻⁵ | 0.0350 |
| A90 | 1 | 1.39×10⁻⁵ | 0.0350 |
| B | **1** | **1.39×10⁻⁵** | 0.0350 |
| C | **1** | **1.39×10⁻⁵** | 0.0350 |

`coverage.json` 同时给出 `starts_unique = 1`、`start_std = 0`。这不是"起点分布很窄"，而是**完全没有分布**：所有 B/C 示范都从同一个 HOME 出发。

在真实交接中，A 的终态却是：

| 技能 | 距 HOME (rad) 均值 [min, max] | 末端位置均值 (m) | 物体 yaw | 平均 ticks |
|---|---|---|---:|---:|
| A0 | **2.004** [1.982, 2.018] | (0.5514, 0.1761, 0.0332) | ≈ +1° | 99 |
| A90 | **1.650** [1.634, 1.661] | (0.5521, 0.1760, 0.0343) | ≈ −90° | 141 |

A0 与 A90 终态的关节差异主要在 joint 1/3/5 与 joint 7（A90 的 joint7 均值 0.898 vs A0 −0.509，HOME 0.78），说明 A90 结束时腕部确实转过了。数据见 `results/experiment_2_1/snapshots/terminal_summary.json`，逐条 40 个快照在 `snapshots/*.json`。

### 2.1 状态距离：能解释什么、不能解释什么

实验 2.1 的覆盖分析（全示范帧的 kNN，`results/experiment_2_1/coverage/coverage.json`）：

| 指标 (rad) | A0 终态 | A90 终态 |
|---|---:|---:|
| 到 HOME 的最近距离 | 2.00 | 1.65 |
| 到 B 示范帧的最近距离 | 1.71 | 0.76 |
| 到 C 示范帧的最近距离 | **0.13** | 0.74 |
| 到全部示范帧的最近距离 | 0.13 | 0.74 |

这组数字与组合结果方向一致（A0→C 20/20，A90→C 0/20；A0→B、A90→B 都 0/20），但**必须注明**：kNN 用的是**所有示范帧**，不是"起点"；C 的轨迹本来就会经过 A 的放置区附近，所以 A0 终态离 C 帧很近，不等于 C 从该起点被训练过。距离只是分布覆盖指标，不能当因果证据。冻结 VLA 的 rollout 才能判断可执行性——这正是 2.3 要补的。

## 3. B 的原子能力：yaw 分层才是关键

用实验 2 的 20 个测试种子（40000000–40000019）重新拆 `eval_B.json` 与专家基线：

| 模型 | 物体 yaw≈0°（长轴 Y） | 物体 yaw≈90°（长轴 X） | 合计 |
|---|---:|---:|---:|
| 冻结 SmolVLA | **1/12 = 8%** (95% CI 1.5–35%) | **7/8 = 88%** (53–98%) | 8/20 = 40% |
| 专家 | **10/12 = 83%** (55–95%) | **8/8 = 100%** (68–100%) | 18/20 = 90% |

- 失败原因全部是 `push_check`：物体前缘没贴到墙（gap > 2 cm）或推动过程中 yaw 变化 > 15°。
- 实验 2 报告的"B 40%"是两种朝向混合后的平均值，掩盖了 8% vs 88% 的分裂。
- 两种朝向的初始推动距离并不完全可比：物体中心 x≈0.55 时，yaw 0 的前缘深度 2 cm（gap≈0.21 m），yaw 90 的深度 5 cm（gap≈0.18 m）。2.3 设计"不同 yaw 难度可比"时必须显式对齐这个量，否则 yaw0 的低成功率可能混入"推得更远"的因素。
- 专家在 yaw0 也只有 83%，说明这个朝向本身更难（4 cm 短端面推动更容易转），不是单纯的模型缺陷。任何"扩大起点覆盖"的实验都必须把这一点作为独立因素报告。

对 2.3 的直接含义：

- **A0→B 的失败不能只归因于机器人起点**。A0 终态物体 yaw≈0，正好落在 B 最弱的朝向上；A90 终态 yaw≈90，是 B 最强的朝向。2.2 的 Physical Retreat 结果与此一致：退让后 A90→B 20/20，而 A0→B 只有 4/20。
- 2.3 的 D1/D2 若不同时匹配 yaw 分布，成功率差异会被朝向组成直接污染；**评测必须按 yaw 分层报告**，并给出 yaw×起点类型的联合表。

## 4. 评测协议与物理退让

### 4.1 统一判据 v2.2

实验 2.2 定的统一协议（`scripts/eval_handoff_timing.py` 的 `task_ok` / `final_ok`）：

1. 任务条件首次满足 → 停止发送新动作；
2. 保持最后命令静置 **1.0 s**；
3. 复核：B 要求前缘 gap ∈ [0, 2 cm]、侧向位移 ≤ 2 cm、yaw 变化 ≤ 15°、倾角 ≤ 12°、速度 < 0.01；C 要求托盘中心 x 误差 ≤ 2 cm、y 误差 ≤ 5 cm、长轴 Y 误差 ≤ 12°、倾角 ≤ 12°、已释放、稳定。

实验 2 的组合评测（`eval_skill_composition.py`）用的是**更早的 b_done/a_done**：没有 1.0 s 静置与最终复核。2.2 的协议审计已把 20/20 与 10/20 的冲突拆开（最多 2/20 来自判定窗口，其余是交接状态差异），并决定后续统一到 v2.2。**2.3 必须继续使用 v2.2，不得为了新模型改判据或切换时机。**

### 4.2 Physical Retreat 是连续控制

`scripts/eval_physical_retreat.py` 的退让实现：

- `execute_joint_path` 每个物理步 `sim.command(q + delta*k)` 后 `sim.step()`，关节步长 `--joint-step 0.002 rad`；
- 全程不用 `resetJointState`（只在 episode 开始时 `restoreState` 恢复快照，属于诊断允许的相同起始条件）；
- 直接路径失败才回滚到快照改走"先抬升 8 cm 再回"的分段路径；实验 2.2 的 80 次全部走直接路径；
- 判据：到达 HOME 误差 < 0.06 rad、无碰撞、物体位移 < 5 mm、A 任务仍成立。

结果（2.2）：80/80 到达 HOME、0 碰撞、物体位移 2.3×10⁻⁶ m、829 个控制周期 ≈ 3.45 s 仿真（墙钟 0.17 s）。

## 5. 关键对照（2.2 已完成，2.3 的背景）

| 组合 | Hard Switch | Physical Retreat | Oracle HOME |
|---|---:|---:|---:|
| A90→C | 0/20 | 18/20 | 19/20 |
| A90→B | 0/20 | 20/20 | 17/20 |
| A0→C | 10/20 | 17/20 | 19/20 |
| A0→B | 0/20 | 4/20 | 1/20 |

这张表说明：恢复 HOME 能救 A90 链，但救不了 A0→B；而 A0→B 的瓶颈正好是第 3 节的 yaw0 原子能力。2.3 的"多起点"假设必须能解释一个额外收益：**在不回 HOME 的前提下，让 B 在 yaw0 与 yaw90 都从非 HOME 构型启动**。

## 6. 对 2.3 数据设计的直接约束

1. **yaw 分层**：D1/D2 都要保证 yaw≈0 与 yaw≈90 的样本数、初始 gap 分布、推动距离尽量匹配；报告要按 yaw 拆分。
2. **起点与 yaw 解耦**：不要把"更多样的机器人构型"和"更容易的物体朝向"绑定；采样时交叉平衡。
3. **起点合法性不等于专家可执行**：物理合法（限位/无碰撞/相机可见/IK 可达）只是第一道门；必须先用 B 专家冒烟证明新起点上能真正推动，再扩大采集。
4. **测试起点独立**：训练/测试种子分开；新测试构型不能复用训练采样起点。
5. **协议冻结**：组合评测继续用 v2.2；A 成功判据、切换时机、静置窗口不变。

## 8. 局限

- 本审计是**只读复核**，没有重跑实验 2 的评测；B 的 yaw 拆分基于原 20 个测试种子（12 vs 8，样本不平衡），置信区间较宽。
- A 终态来自 2.1 的 20+20 个真实 rollout，未覆盖所有 A 成功模式；2.3 若需要更大规模终态分布，应重新采集。
- 覆盖距离用的是全示范帧 kNN，不能直接解释组合成功/失败；真正的判断必须来自冻结 VLA rollout。
- 2.2 的退让只在 HOME 目标、无障碍场景验证；2.3 不重复该基线，只引用协议匹配的数字。
