# 实验 4.1 阶段说明

## 目标

为未来"多 A × 多 B 零样本组合"研究建立**物理真实、目标明确、覆盖充分**的原子技能数据基础，
并先建立**经过物理验证的严格成功评价器**。

本轮不做：π₀.₅ 训练/微调、正式 A→B 组合评测、6D 与七关节连接方法比较。

## 阶段划分与门槛

| 阶段 | 内容 | 门槛 |
| --- | --- | --- |
| 1 | 动作/时间语义冻结（`environment_and_action_contract.md`） | 绝对关节目标 ↔ π₀.₅ 增量语义可逆；相位检查通过 |
| 2 | 严格评价器（`src/exp41/strict_eval.py`） | 17 个物理正负案例全过 |
| 3 | Pilot（A90 27 次 / B90 18 次） | 多 A 终态成立；B90 真实推墙；provenance 完整 |
| 4 | 有界采集（45 + 45） | 全部通过严格评价；失败保留；预算内 |
| 5 | 回环与划分 | 90/90 episode 通过 48/48 校验；split 预注册 |

## 关键实现

- `src/exp41/scene41.py`：显式场景（权威 body id）、9 个 A 目标、3 个 B 目标区、3 个物体起点、
  2 个机器人起点、预配对关系、相机 v3；
- `src/exp41/strict_eval.py`：`PhysicsMonitor` 包住 `sim.step()`，每个 240 Hz 物理步记录接触；
  A90/B90 各自的 `checks` 与 `failure_reason`；
- `src/exp41/experts41.py`：参数化 A90（目标/偏置/释放/撤离等开关，后者仅用于负例构造）与
  B90（+X 推进直到真实接触、可选横向修正）；
- `src/exp41/run41.py`：一次尝试的完整链路（场景→监控→专家→稳定窗口→评价→记录）；
- `scripts/exp41/*.py`：评价器案例、pilot/采集、注册表、回环校验、多样性/split/统计、
  旧判据对照、15 Hz 可行性、目标条件测试。

## 与实验 3 的对应

实验 3 的 6 个发现 → 4.1 的处理：

| 实验 3 发现 | 4.1 处理 |
| --- | --- |
| 选定 B 起点的关节规划可成功 | B 数据改为**独立启动**（不同物体起点 + 机器人构型），不再是"A 终态后接 B" |
| 严格匹配状态无额外损失 | 本轮不测组合损失（留给 4.3） |
| 场景变化显著影响后继策略 | 本轮把"场景"显式拆成 B 物体起点 / B 机器人起点 / B 目标三个维度 |
| D2 原子技能执行不稳定 | 严格判据 + 失败原因分类，B90 72.6% 的成功率如实报告 |
| 旧近墙判据 ≠ 任务完成 | 替换为真实接触 + 目标区 + 姿态 + 稳定性判据 |
| A90 只有一个唯一终态 | 9 个目标 → 9 种实测终态 |
