# 实验 2.1：VLA 未见技能组合的交接状态归因诊断

## 摘要

用**冻结的 SmolVLA**（20 000 步 checkpoint）和 40 个真实 A 终态快照，做了 320 次 T0/T1/T2/T3 受控评测，回答"组合失败到底来自哪个状态分量"。

**核心结论：主因是前序技能留下的机器人关节构型，而不是物体状态或语言条件。**

- A90→C：真实交接 **0/20**；只把机器人恢复 HOME、物体完全不动 → **19/20**。
- A90→B：0/20 → **17/20**。
- A0→C：10/20 → **19/20**。
- A0→B：0/20 → 1/20 —— 这一组退化到 B 自身在 yaw 0 上的短板（HOME 起点的 B 也只有 5%）。

同时确认：**语言条件没有失效**。同一状态下，B 指令会让模型"闭爪 + 水平推"，A 指令会让它"张爪 + 抬升"；A→B 的"抓起物体"是因为交接时夹爪已经在物体两侧，闭爪后推变成了抓。

## 1. 方法与冻结

| 项 | 值 |
|---|---|
| checkpoint | `outputs/smolvla_multi/checkpoints/020000/pretrained_model` |
| sha256 | `b7924be7…f641d` |
| 控制 | 20 Hz，chunk 50，256×256，ss=1 |
| 测试种子 | 40000000–40000019 |
| 快照 | 40 个（A0/A90 各 20），恢复后关节/物体/图像逐位一致（偏差 0，图像 MAE 0） |

四种条件（只改机器人/物体，不改任务指令与判据）：

| 条件 | 机器人 | 物体 |
|---|---|---|
| T0 | A 终态 | A 终态 |
| T1 | HOME | A 终态 |
| T2 | A 终态 | 标准起点（PLACE, yaw 0） |
| T3 | HOME | 标准起点 |

T0 不做额外 settle（只设置电机目标后立即开始后继技能）；T2/T3 的构造只发生在诊断开始前，执行阶段完全由 VLA 控制。构造后做物理有效性检查（关节限位、穿插、高度、静止）。

## 2. 主结果

| 组合 | T0 | T1 只恢复机器人 | T2 只恢复物体 | T3 全标准 |
|---|---:|---:|---:|---:|
| A0→B | 0/20 | 1/20 | 0/20 | 1/20 |
| A90→B | 0/20 | **17/20** | 无效 | 1/20 |
| A0→C | 10/20 | **19/20** | 14/20 | **20/20** |
| A90→C | 0/20 | **19/20** | 无效 | **20/20** |

![条件对比](results/experiment_2_1/diagnosis/conditions.png)

T2 在两条 A90 链上全部无效：把物体从 yaw −90° 转到 0° 时，A90 终态的夹爪与物体有 **13 mm 穿插**，物理上无法初始化。

## 3. 三个状态分量的作用

### 3.1 机器人构型（主导）

四条链里 T0→T1 都是最大提升：+19、+17、+9、+1（A0→B 例外，见 3.3）。

A90→C 最干净：物体保持 yaw ≈ −90° 不变，只把机器人放回 HOME，成功率从 0/20 变成 19/20。**C 完全能处理旋转后的物体**，失败来自 A90 留下的腕部构型（q7 差 1.41 rad，q1/q3/q5 差 0.22–0.26 rad）。

### 3.2 物体朝向（对 B 决定性，对 C 很小）

- 同为 HOME 机器人：A90→B 的 T1（物体 yaw −90°）17/20，T3（物体 yaw 0°）1/20。
- 原子评测同样如此：B 的 8 次成功里 yaw≈90° 占 7/11，yaw≈0° 只有 1/9。
- C 对朝向几乎不敏感：T1 19/20 vs T3 20/20。

所以 **A0→B 的 0% 主要不是组合问题**：A0 留下的是 yaw 0，正好是 B 学得最差的朝向。

### 3.3 A0→B：四种条件都接近 0

T0 0/20、T1 1/20、T2 0/20、T3 1/20。机器人怎么恢复都没用，因为物体朝向是困难项。这一组应当从"组合失败"里拿出来单独报告为"原子技能短板"。

## 4. A90→C 专项（阶段 4）

| 检查 | 结果 |
|---|---|
| 7 关节终态差异 | q7 差 1.41 rad（≈81°）；q1/q3/q5 差 0.22–0.26 rad |
| 关节限位余量 | 最小 1.05 rad，**没有任何关节接近限位** |
| 物体位置 | A0 (0.552, 0.183) vs A90 (0.557, 0.179)，差 <5 mm |
| 物体 yaw | A0 0.9°±1.0°，A90 −90.4°±1.6° |
| HOME + 物体 yaw −90°（T1） | 19/20 |
| HOME + 物体 yaw 0°（T3） | 20/20 |

物体 yaw ±90° 对长方体是几何等价的（绕 Z 转 180° 对称），因此没有单独跑 +90°/−90° 对照：若两者出现差异，只能说明渲染/表示层面的不对称，而不是物理差异。T1 与 T3 已经说明 C 对物体朝向不敏感。

结论：A90→C 的失败**不能**归因于关节限位、物体位置或物体朝向，只能归因于腕部/手臂构型。

## 5. B 的语言条件对照（阶段 5）

同一交接状态，只改语言指令，比较首个 50 步动作块：

| 指标 | B 指令 | A 指令 |
|---|---|---|
| 夹爪均值 | 0.0167–0.0188（**闭合**） | 0.0398–0.0400（**张开**） |
| 闭合步数 | 50/50 | 0/50 |
| 末端水平位移 | 4.2–7.3 cm | 0.4–0.9 cm |
| 末端垂直位移 | −0.4 ~ +1.2 cm | **+11.3 ~ +15.0 cm** |

8 个状态、2 种指令，模式完全一致。**语言条件没有失效**：B 指令产生"闭爪 + 水平推"，A 指令产生"张爪 + 抬升"。共享模型没有把 Push 和 Pick 混淆。

那 A→B 为什么把物体抓起来？因为在交接状态里夹爪已经跨在物体两侧，B 策略的第一个动作就是闭合夹爪——闭合后推就变成了抓。**是正确动作在错误状态下产生了错误物理效果**，不是指令理解错误。

## 6. 训练状态覆盖（阶段 6）

B/C 数据集共 15 657 帧（每 2 帧取 1），起点只有 1 个唯一值（HOME）。关节空间最近邻距离（7 维欧氏，rad）：

| A 终态 | 到 B 训练状态 | 到 C 训练状态 | 到 HOME |
|---|---:|---:|---:|
| A0 | 1.71 | **0.13** | 2.00 |
| A90 | 0.76 | **0.74** | 1.65 |

PCA 前两维解释 49% / 37% 方差。

![PCA](results/experiment_2_1/coverage/pca.png)

读法：A0 终态离 C 的轨迹状态很近（0.13 rad），但 T0 仍只有 50%；A90 终态离 C 的轨迹状态较远（0.74 rad），T0 为 0。恢复 HOME 后两者都回到 95–100%。**关节空间距离与成功率相关但并不决定成功率**，不能仅凭"距离近"断言可执行。

## 7. 对研究问题的回答

**Q1：A90→C 失败主要与机器人构型、物体状态还是两者共同有关？**
机器人构型。物体完全不动、只恢复构型就 19/20；物体朝向对 C 几乎无影响。

**Q2：单独恢复机器人到 HOME 能否显著恢复 C？**
能。A90→C 0→19/20，A0→C 10→19/20。

**Q3：单独恢复物体状态能否恢复成功率？**
对 C 部分有效（A0→C 50→70%），对 A90 链无法构造（物理穿插）。远不如恢复机器人有效。

**Q4：B 执行错误抬升的原因？**
不是语言条件、不是共享模型混淆。同一状态下 B 指令确实生成"闭爪 + 水平推"；抬升是"在夹爪已经夹住物体时闭爪"的物理后果。

**Q5：A 终态是否偏离 B/C 的训练起点分布？**
是，而且很大：A0 到 HOME 2.00 rad，A90 1.65 rad；B/C 的起点只有一个点（HOME）。

**Q6：这种分布偏移与实际成功有关吗？**
有，但不是单调关系。A0→C 距离 C 状态 0.13 rad 仍只有 50%（T0），A90 0.74 rad 为 0%；恢复 HOME 后恢复到 95–100%。距离只能作为风险提示。

**Q7：有证据表明扩大机器人状态覆盖能改善组合吗？**
有。只把机器人恢复到训练分布中的 HOME 就把三条链恢复到 85–100%，说明覆盖机器人构型是当前最直接的改进方向；同时 B 的朝向覆盖极不均衡（yaw 90 与 yaw 0 差 7 倍），需要联合补齐。

**Q8：如果数据覆盖不是主要问题，是否必要研究推理期引导？**
仍值得研究，但不是当前最紧的。A0→C 在构型距离仅 0.13 rad 时仍掉到 50%，说明还有"交接瞬间细节"这类靠扩数据未必能完全覆盖的因素；在修好覆盖之后，可行性引导仍有价值。

**Q9：是否存在无法由状态恢复/物体调整/硬切换解释的失败？**
有两处：(a) 实验 2 的 A0→C 100% 与本阶段 T0 的 50%，差别只在交接时刻（判定当 tick vs 稳定 1.2 s 后）；(b) A0→C 的 T0 50% vs T2 70%，物体只差 2–3 mm。这两处说明交接瞬间的机械臂/接触细节有额外影响，不能用简单的状态重置解释。

## 8. 结论与建议

1. **路线 A（数据覆盖）应优先**：B/C 采集时随机化机器人初始关节构型（覆盖 A 终态附近），并补齐 B 在 yaw 0 上的示范。这是本轮证据最直接支持的改进。
2. **路线 B（推理期引导）保留**：在覆盖修好之后，如果 A0→C 仍出现"构型接近但失败"的情况，再引入后继可行性引导。
3. **不要**把 A0→B 的组合失败当作组合问题的证据——它是 B 的原子短板。

## 9. 局限

- 每条件 20 次，0/20 的置信区间上界是 16%。
- T0 是"释放并稳定后"的快照，与实验 2 的"判定当 tick 切换"不同；A0→C 的 50% vs 100% 即由此而来。
- T2 在 A90 链上全部无效，A90 的物体因素只能通过 T1/T3 间接判断。
- T3 只定义了一种标准物体位姿（yaw 0）；若定义为 yaw 90°，B 的数字会不同（见 3.2）。
- 阶段 5 的 chunk 对比是在同一观测上展开 50 步，不是完整闭环；它用于判断语言敏感性，不替代组合成功率。
