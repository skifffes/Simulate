# 实验 2.2：交接时机与真实物理连接的组合归因

## 摘要

用冻结的 20 000 步 SmolVLA，在 40 个真实 A 终态上做了三组实验：交接协议审计、交接时机对照（H0/H2/H3）、以及"连续关节运动退回 HOME"的物理连接基线。

**结论：当前观察到的组合失败，绝大部分可以由"交接时机 + 一个最朴素的运动规划连接器"解释或解决。**

| 组合 | Hard Switch | Best Valid Timing | Physical Retreat | Oracle HOME（参考） |
|---|---:|---:|---:|---:|
| A90→C | 0/20 | 0/20 (三种时机均 0) | **18/20** | 19/20 |
| A90→B | 0/20 | 未测 | **20/20** | 17/20 |
| A0→C | 10/20 | **17/20 (H0)** | **17/20** | 19/20 |
| A0→B | 0/20 | 未测 | 4/20 | 1/20 |

- A90 链：真实退让后从 0% 恢复到 **90–100%**，与 Oracle HOME 持平。
- A0→C：时机影响明显（立即 85% vs 等 1.2 s 55%，McNemar p≈0.070）；退让后 85%。
- A0→B：无论时机还是退让都救不回来——瓶颈是 B 在物体 yaw≈0° 时的原子能力。

## 1. 实验设置

| 项 | 值 |
|---|---|
| checkpoint | `outputs/smolvla_multi/checkpoints/020000/pretrained_model`（sha256 `b7924be7…`） |
| Git（本轮开始时） | `7d9e1bb` |
| 控制 | 20 Hz，chunk 50，256×256，ss=1 |
| 测试种子 | 40000000–40000019 |
| 判据 | 统一协议 v2.2（见下） |
| 统计 | Wilson / McNemar 精确检验 |

**统一判据 v2.2**：任务条件满足且已释放 → 停止发新动作、保持最后命令静置 1.0 s → 复核位置/朝向/倾角/released/速度。

**四个方法**：
- Hard Switch：A 成功的稳定快照直接切换（= 2.1 T0）；
- Best Valid Timing：在 `t_a_success` 当 tick 切换（H0；H2/H3 为等 0.6/1.2 s）；
- Oracle HOME：仿真状态瞬时恢复 HOME（2.1 T1，仅参考，不可执行）；
- Physical Retreat：连续关节运动退回 HOME，再运行后继 VLA。

## 2. 阶段 1：协议审计

实验 2 的 A0→C 20/20 与 2.1 的 10/20 差异拆解：

- 2.1 T0 的 10 次失败里，**8 次物体从未离开放置区**（交接状态差异），**2 次到达托盘后继续跑 260 tick 把 yaw 漂出容差**（判定窗口差异）。
- 因此判据最多解释 2/20，其余是真实的状态差异；两套历史数字不能直接比较。

## 3. 阶段 2：交接时机

从同一 `t_a_success` 分支（10 + 10 个状态）：

| 组合 | H0 立即 | H2 等 0.6 s | H3 等 1.2 s |
|---|---:|---:|---:|
| A0→C（20 状态） | **17/20 (85%)** | 12/20 (60%) | **11/20 (55%)** |
| A90→C（20 状态） | 0/20 | 0/20 | 0/20 |

A0→C 的 H0 vs H3：7 个状态由成功变失败、1 个反向，McNemar **p ≈ 0.070**（边缘显著）。

但效果**不均匀**：前 10 个状态里 5 次翻转、0 次反向；后 10 个只有 2 次翻转、1 次反向——是否受时机影响取决于具体状态。

**等待期间物理状态几乎没变**：H0 与 H3 切换瞬间关节最大差 **0.0066 rad**、物体位移 **0.3 mm**、yaw 差 0.006 rad。所以不是机械臂漂移或物体被碰，而是**冻结的 flow-matching 策略对交接点微小扰动极其敏感**。

从 2.1 快照再额外等待 0/0.6/1.2 s 没有进一步影响（4/3/4 of 10）——关键窗口是 A 成功后的第一个 1.2 s。

> 注：H1（chunk 边界切换）在本设置下退化：`t_a_success` 时动作队列只剩 0–3 个动作，H1 与 H0 实际不可区分。

## 4. 阶段 3：Physical Retreat to HOME

从 A 的真实终态出发，用连续关节运动（步长 0.002 rad）退回 HOME；任何机器人接触（物体/桌面/墙/托盘/自碰撞）都算碰撞，触发回滚并改用"先抬升再回"的分段路径；禁止瞬移。

**80 次退让全部成功**：

| 指标 | 结果 |
|---|---|
| 到达 HOME（误差 <0.06 rad） | 80/80 |
| 路径 | 80/80 直接关节路径 |
| 碰撞 | 0 |
| 物体位移 | 2.3×10⁻⁶ m |
| 退让后 A 仍成功 | 80/80 |
| 耗时 | 829 个控制周期 ≈ 3.45 s 仿真（墙钟 0.17 s） |

### 各组合结果

| 组合 | Hard Switch | Physical Retreat | Oracle HOME |
|---|---:|---:|---:|
| A90→C | 0/20 | **18/20** | 19/20 |
| A90→B | 0/20 | **20/20** | 17/20 |
| A0→C | 10/20 | **17/20** | 19/20 |
| A0→B | 0/20 | **4/20** | 1/20 |

失败类型：A90→C 的 2 次是放置后的 `final_check`（静置复核时位置/朝向超差）；A0→C 的 3 次是 `timeout`；A0→B 的 16 次是 `timeout`（B 在 yaw 0 上抓不住/推不动）。

## 5. 研究问题回答

**Q1：实验 2 的 20/20 与 2.1 的 10/20，是否由交接时机或评测协议造成？**
主要是时机。统一判据下：立即切换 17/20、等 1.2 s 11/20（p≈0.070）；2.1 的 10/20 与"等 1.2 s"同量级，实验 2 的 20/20 与"立即"同量级。协议（判定窗口）最多解释 2/20。

**Q2：延迟切换会提高还是降低后继成功率？对应哪些状态变化？**
降低 A0→C（85%→55%），对 A90→C 无影响。状态变化只有 0.0066 rad / 0.3 mm，说明是策略对交接点扰动的敏感性，而不是明显的物理退化。

**Q3：不使用瞬移，机械臂能否从 A90 真实终态安全回到 HOME？**
能，80/80 全部直接关节路径成功，零碰撞，物体位移在数值噪声量级。

**Q4：真实回 HOME 后，A90→C 和 A90→B 能否恢复接近 Oracle HOME？**
能。A90→C 18/20（Oracle 19/20），A90→B 20/20（Oracle 17/20）。

**Q5：Physical Retreat 失败在哪里？**
本轮没有退让失败（0 路径不可行、0 碰撞、0 物体扰动）。失败全部在后继 VLA：A90→C 的 2 次放置后稳定性、A0→B 的 16 次 B 原子短板。

**Q6：改善是否来自恢复机器人状态，而不是改变物体或任务条件？**
是。物体位移 <3 μm、A 条件 80/80 保持、任务/判据/相机/语言完全不变，唯一变量是机器人关节构型。

**Q7：简单的交接时机调整与传统运动规划，是否足以解决当前观察到的主要失败？**
对 A90 链：是，退让已经把它从 0% 恢复到 90–100%，不需要任何新方法。对 A0→C：时机与退让都能到 85%，仍略低于 Oracle 的 95%。对 A0→B：不能，瓶颈是原子技能。

**Q8：还有哪些失败不能被上述方法解释？**
1. A0→C 的 17/20 vs Oracle 19/20（约 10%），来自 C 在该状态下的抓取/放置稳定性，与构型无关。
2. 时机效应的**状态依赖性**：前 10 个状态 5 次翻转、后 10 个 1 次，目前无法从可观测量预测哪些状态敏感。
3. A0→B 的 4/20：B 在 yaw≈0 的原子能力（原子评测 1/9），需要数据或技能层面的改进。
4. A90→C 退让后的 2 次 `final_check`：放置完成后物体在 1 s 静置中移出容差。

## 6. 路线判断

- **情况 B 成立**：真实物理退让已足够有效。传统运动规划是一个强 Baseline，任何新的生成式方法（Flow Bridging / 后继可行性引导）必须在 A90 链上超过 90–100% 才有意义，或者证明更低的动作成本/不依赖完整几何。
- **情况 A 部分成立**：A0→C 的交接时机确实是评测协议问题，20/20 与 10/20 的冲突主要来自"何时切换"。
- **情况 D 部分成立**：A0→B 的失败来自原子数据/技能覆盖，需要独立的原子数据增强实验，而不是组合方法。

## 7. 局限

- 退让只用 HOME 作为目标，且 80/80 都不需要绕障；更复杂场景结论可能不同。
- Oracle 几何仅用于碰撞检查，纯视觉方法的信息权限不同。
- 时机实验的 A→B 未测；A90→C 的时机在 20 个状态上全 0，无法判断是否存在敏感子集。
- 每组合 20 次，置信区间约 ±10–13 个百分点；时机效应的异质性需要更多状态才能建模。
- 退让目标 HOME 恰好是训练分布起点，这是它有效的前提。
