# 实验 2.3 阶段 3：D1/D2 原子 B 数据采集

## 摘要

按 prompt.md 的"数据预算一致的对照"要求，采集了两个 **480 集完整数据集变体**（只替换其中的 B 原子数据）：

| 变体 | B 数据 | 机器人起点 | 物体分布 | 结果 |
|---|---|---|---|---|
| **D1** | 120 条 | 全部 HOME（canonical control） | 120 个 spec | 201 次尝试，120 条成功；14 759 帧 |
| **D2** | 120 条 | 60 条 HOME + 60 条合法多样起点 | **完全相同的 120 个 spec** | 132 次尝试 + 1 次 HOME 回退，120 条成功；14 653 帧 |

两个完整数据集都是 **480 集 / 4 任务**：B 帧数相差 **0.7%**（14 759 vs 14 653），完整数据集帧数相差 **0.15%**（68 998 vs 68 892），并通过了与实验 2 相同的数据校验：**11 540 项检查、0 失败、动作回放误差 1×10⁻⁵ rad**。

本阶段只采数据，**没有训练、没有跑组合评测**。关键观察：

1. **canonical B 的瓶颈集中在 yaw≈0**：D1 在 yaw0 的专家尝试成功率 **45.5%**（60/132，失败 55 次是 `b_push_6`），yaw90 为 **87.0%**（60/69）。这与实验 2 冻结 VLA 的 yaw0 **1/12** 相互印证——yaw0 推动是整条链路最脆弱的环节。
2. **D2 的多样起点没有降低专家整体成功率**：在 D1 已成功的同一批 spec 上，D2 首次尝试成功 110/120；10 次失败全部通过换起点或 HOME 回退补齐，最终 120/120 入库。
3. **起点覆盖到位**：D2 的 59 个多样起点关节距离为 **0.11–2.51 rad**，其中 multi-IK 0.96–2.51 rad、task-relevant 1.03–2.29 rad，覆盖 A0（2.00 rad）与 A90（1.65 rad）真实终态区间；D1 的起点唯一值仍是 1 行（HOME）。
4. **物体分布严格配对**：D1/D2 复用同一份 120 个 spec（yaw 各 60），x 0.538–0.562 m、y 0.168–0.192 m；yaw0 初始 gap 0.196–0.221 m、yaw90 0.167–0.191 m。**gap 的 yaw 差异（约 3 cm）是长方体深度造成的，本轮没有强行对齐**（见 §6）。
5. 采集总墙钟约 **55 分钟**（D1 19:05–19:31，D2 19:33–19:59，服务器单进程 PyBullet DIRECT，两组 D1 并行）。

## 1. 目标与边界

本轮要建立一个**只改变机器人起点、不改变物体分布与示范数量**的对照，供后续训练回答：

> 扩大 B 的机器人起点覆盖，能否在不提供组合示范的前提下提高 A→B 的直接交接成功率？

因此本阶段严格限定：

- 只采 B 的独立原子示范；不采 A→B 连续轨迹，不使用任何组合成功/失败标签；
- D1 与 D2 的物体 spec、示范条数、任务语言、相机、动作表示完全一致；
- 两个完整数据集复用实验 2 的 A0/A90/C 各 120 条，只替换 B；
- 不做训练、不做组合评测；D3（额外数据量）不做。

## 2. 设计

### 2.1 物体 spec：D1/D2 完全配对

`scripts/collect_b_e23.py` 按实验 2 的原始 B 分布生成物体初始状态：

| 项 | 值 |
|---|---|
| 位置 x | 0.550 ± 0.012 m |
| 位置 y | 0.180 ± 0.012 m |
| 朝向 | yaw 0 / 90 ± 0.10 rad，各 60 条 |
| 高度 | 0.021 m（底面贴桌） |
| friction | 1.2（实验 2 固定值） |
| 采集种子 | yaw0 `52000000+`、yaw90 `53000000+` |

D1 先按 yaw 组各采 60 条成功示范；D1 实际使用的 **120 个 spec** 原样写入 `used_specs.json`，D2 直接复用这 120 个 spec（同一 seed、同一位置、同一朝向）。因此**物体分布的差异为 0**，唯一的自变量是机器人起点。

### 2.2 机器人起点

| 变体 | 调度 |
|---|---|
| D1 | 全部从 HOME 出发 |
| D2 | 每个 yaw 组 60 条：30 条 HOME、30 条多样起点（HOME 邻域 / 多 IK / 任务相关按 2:1:1 轮换） |

多样起点来自阶段 1 的 `starts.sample_valid_start`：关节限位余量、静态碰撞、夹爪-物体间距、物体稳定、top 相机视锥、B 接近位姿 IK、关节路径粗检七项全部通过才允许使用；测试/采集种子（70 000 000+）与训练/测试种子隔离。

### 2.3 为什么没有强行对齐 yaw 的初始 gap

yaw0 的物体深度是 2 cm、yaw90 是 5 cm；在 x≈0.55 时两者初始 gap 相差约 3 cm。曾尝试按 gap 反推 x（yaw0 推到 0.59、yaw90 移到 0.53），但在 `x≈0.569、gap≈0.188` 的 yaw0 spec 上，20 Hz 录制专家 **3/3 失败于 `b_push_6`**（手臂在末段靠近挡板，跟踪误差超限）。因此保留实验 2 的原始物体分布：

- 优点：与历史 B 数据同分布，且不会把"更容易推的朝向"与"更靠近墙的起点"绑定；
- 代价：yaw0 的初始 gap 系统性大于 yaw90（0.196–0.221 vs 0.167–0.191），后续比较 yaw 时必须显式分层，不能把差异全部归因于朝向难度。

## 3. 采集结果

### 3.1 D1（canonical）

| 指标 | yaw0 | yaw90 | 合计 |
|---|---:|---:|---:|
| 成功入库 | 60 | 60 | **120** |
| 尝试次数 | 132 | 69 | **201** |
| 尝试成功率 | 45.5% | 87.0% | 59.7% (95% CI 52.8–66.2%) |
| 平均控制周期（成功集） | 127.8 | 118.1 | 123.0 |
| B 帧数 | — | — | **14 759** |

失败原因（yaw0）：`b_push_6` 55 次、`push_check` 11 次、`b_retreat` 5 次、`b_push_5` 1 次；yaw90 只有 `b_push_2` 9 次。**yaw0 的失败几乎全部发生在推的末段**，与阶段 0 审计中冻结 VLA 的失败模式一致。

### 3.2 D2（50% diverse start）

| 指标 | 值 |
|---|---:|
| 成功入库 | **120** |
| 常规尝试 | 132 + 1 次 HOME 回退 |
| 尝试成功率 | 90.2%（119/132；含回退为 120/133） |
| 首次尝试成功率 | **91.7%**（110/120） |
| yaw0 尝试成功率 | 83.1%（59/71；含回退 60/72） |
| yaw90 尝试成功率 | 98.4%（60/61） |
| 平均控制周期（成功集） | 122.1 |
| B 帧数 | **14 653** |

最终 120 条数据的起点构成：

| 起点模式 | 条数 | 起点到 HOME 距离 mean [min, max] (rad) |
|---|---:|---:|
| HOME | 61 | 0 [0, 0] |
| HOME 邻域 | 31 | 0.352 [0.106, 0.482] |
| 多 IK | 14 | 1.589 [0.963, 2.507] |
| 任务相关 | 14 | 1.664 [1.032, 2.294] |
| **多样起点合计** | **59** | **—** |

计划是 60 条多样起点；index 56 的多样起点连续失败后回退 HOME，因此最终 59 条多样 + 61 条 HOME。多样起点共有 **59 个不同的关节构型**，覆盖 0.11–2.51 rad。

> **注意选择性**：D2 的尝试成功率不能直接与 D1 的 59.7% 比较。D1 的 201 次尝试包含大量**未通过**的 spec；D2 只使用 D1 已经成功的 120 个 spec。正确的同分布比较是"同一 120 个 spec 的首次尝试成功率"：D1 = 120/120（按定义），D2 = 110/120。也就是说，**多样起点让首次尝试多了约 8% 的失败**，但没有改变"最终能否采到 120 条"。

## 4. 数据预算匹配

| 项 | D1 | D2 | 比值 / 差异 |
|---|---:|---:|---|
| B 示范条数 | 120 | 120 | 相同 |
| B 帧数 | 14 759 | 14 653 | 0.993（−0.7%） |
| 完整数据集 episode | 480 | 480 | 相同 |
| 完整数据集帧数 | 68 998 | 68 892 | **0.998（−0.15%）** |
| 任务数 | 4 | 4 | 相同 |
| 观测/动作维度 | 9 / 8 | 9 / 8 | 相同 |
| 相机 | top + wrist 256×256 | 同 | 相同 |
| 演示平均长度 | 123.0 ticks | 122.1 ticks | −0.7% |

结论：**episode 数与帧数都已匹配**；后续训练可以直接用同样的 20 000 步、batch 8、同一初始化，不需要为 D2 单独调预算。

## 7. 关键观察

1. **yaw0 是 canonical B 的瓶颈，而且不是数据采集器的偶发失败**：45.5% 的尝试成功率、55 次 `b_push_6`，与 VLA yaw0 1/12、专家 yaw0 10/12 形成一致的证据链。D2 想在组合上改善 A0→B，必须同时让模型在 yaw0 上变强，而不只是"见过更多机器人构型"。
2. **多样起点本身不会让专家崩溃**：D2 首次尝试 110/120，失败集中在 yaw0（59/71 尝试成功）；yaw90 几乎不受影响（98.4%）。59 个多样构型中有 28 个距离超过 1.5 rad，仍然全部完成推动。
3. **选择效应必须写清楚**：D1 的 59.7% 是"从原始分布里筛出 120 条成功"的代价；D2 的 90.2% 是"在已筛出的 spec 上再采"。两者不能当作"多样起点更容易"的证据。
4. **yaw 与 gap 的混淆仍在**：yaw0 的初始 gap 平均大 3 cm（推得更远），且 45.5% 的失败集中在末段。后续评测必须按 yaw 分层，最好再补一个 gap 对齐的子集（在不触发手臂-挡板碰撞的 x 范围内）来分离"朝向难度"与"推动距离"。

## 9. 局限

- 只有 B 被替换；A0/A90/C 仍是实验 2 的数据，因此 D1/D2 的差异严格限定在 B 的起点分布，但也意味着**共享模型的其他技能不会因本轮数据而变化**（训练后仍需检查遗忘）。
- D2 的 59 个多样起点是"通过合法性检查 + 专家可行"的切片，不是全部物理合法状态；被拒绝的候选（约 10%）只记录在阶段 1，未在本轮扩大。
- 物体 gap 的 yaw 差异未对齐（§2.3），yaw0 的 45.5% 成功率同时包含"朝向更难"与"推得更远"两个因素。
- 每变体只有 120 条 B、单次采集；采集器/专家的一次性波动未做重复采集估计。
- 未训练、未评测；本阶段的全部结论只关于**数据生成与专家可行性**，不能外推到 VLA 成功率。
- 服务器 `/scratch` 使用率约 98%，本轮新增约 0.6 GB（两个 480 集变体 + shards）；后续训练前应确认磁盘余量。
